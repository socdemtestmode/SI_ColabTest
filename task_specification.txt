# Задание: Создать Python-бота для игровой платформы SIGame

**Цель:** Разработать автономного Python-бота, который автоматизирует процесс создания и запуска игр на платформе SIGame. Бот должен быть выполнен в виде единого скрипта, готового к запуску в облачных средах типа Google Colab.

**Ключевые функции:**

1.  **Автоматическое создание игры:** При запуске бот должен создать новую игровую комнату со следующими параметрами:
    *   **Название:** Динамически генерируемое, по формату `testcolabgame_` с добавлением случайного числа.
    *   **Пароль:** Заранее определённый (`1212`).
    *   **Игровой контент:** Использовать стандартный, пустой пакет вопросов.

2.  **Управление лобби:** После создания комнаты бот должен войти в неё в качестве хоста и ожидать подключения других участников.

3.  **Автоматический старт:** Бот должен отслеживать количество игроков в лобби. Как только к игре присоединятся два человека, бот должен немедленно инициировать запуск игры.

**Технические требования:**

*   **Сетевое взаимодействие:** Бот должен уметь взаимодействовать с API сервера игры. Это включает в себя:
    *   Поиск доступного сервера.
    *   Аутентификацию для получения токена доступа.
    *   Установление и поддержание постоянного WebSocket-соединения для обмена данными в реальном времени.

*   **Обработка протокола:** Бот должен понимать и корректно обрабатывать два уровня протокола:
    *   Протокол управления сессией (на базе SignalR) для создания игры и управления лобби.
    *   Внутриигровой текстовый протокол для отправки команд, таких как "старт игры".

*   **Среда выполнения:** Скрипт должен быть самодостаточным. Он должен автоматически проверять наличие необходимых библиотек (таких как `aiohttp` и `websockets`) и устанавливать их, если они отсутствуют.

*   **Логирование:** Для удобства отладки и мониторинга бот должен выводить в консоль информацию о ключевых этапах своей работы: поиске сервера, создании игры, подключении игроков и старте матча.
