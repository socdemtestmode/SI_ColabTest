# Техническое задание: Разработка игрового бота для SIGame

## 1. Цель

Создать полностью функционального программного агента (бота) для взаимодействия с игровым сервером SIGame. Агент должен быть реализован в виде единого Python-скрипта, предназначенного для запуска в среде Google Colaboratory. Основная задача бота — автоматическое создание игровой комнаты с заданными параметрами и запуск игры при выполнении определённых условий.

## 2. Основные требования

1.  **Создание игры:** По запуску скрипт должен инициировать создание новой игровой комнаты.
2.  **Параметры игры:**
    *   **Название:** Должно генерироваться по шаблону `testcolabgame_XXX`, где `XXX` — случайное число от 001 до 999.
    *   **Пароль:** `1212`.
    *   **Игровой пакет:** Использовать стандартный (пустой) пакет.
3.  **Ожидание игроков:** После создания комнаты бот должен ожидать подключения других участников.
4.  **Автоматический старт:** Игра должна автоматически начинаться, как только в комнате окажется 2 (два) человека (помимо самого бота-хоста).
5.  **Среда выполнения:** Скрипт должен быть полностью совместим с Google Colab, включая автоматическую установку необходимых зависимостей.
6.  **Логирование:** Ключевые события (например, получение токена, создание игры, подключение игрока, старт игры) должны выводиться в консоль для отладки и мониторинга.

## 3. Протокол взаимодействия с сервером

Взаимодействие с сервером является многоэтапным и использует несколько протоколов.

### Этап 1: Обнаружение сервера и аутентификация (HTTP REST API)

1.  **Получение списка серверов:**
    *   **Запрос:** `GET https://vladimirkhil.com/api/si/servers`
    *   **Ответ:** Массив JSON-объектов, содержащих `uri` сервера и `protocolVersion`.
    *   **Действие:** Выбрать сервер с `protocolVersion`, равной 1.

2.  **Аутентификация и получение токена:**
    *   **Запрос:** `POST {serverUri}/api/Account/LogOn`
    *   **Параметры:** `login`, `password` (согласно документации, пароль должен быть пустым).
    *   **Ответ:** В случае успеха сервер возвращает cookie для сессии и одноразовый `token` для подключения к SignalR.

### Этап 2: Установка WebSocket-соединения (SignalR)

1.  **Подключение:** Установить WebSocket-соединение по адресу:
    *   `{serverUri}/sionline?token={token}` (URI сервера преобразуется из `http(s)://` в `ws(s)://`).

2.  **Handshake (рукопожатие):** Сразу после подключения отправить серверу JSON-сообщение для инициализации протокола:
    *   **Сообщение:** `{"protocol": "json", "version": 1}`
    *   **Важно:** Каждое сообщение SignalR должно заканчиваться специальным разделителем `\x1e`.

### Этап 3: Создание игры и управление лобби (SignalR Hub Methods)

Взаимодействие с лобби происходит через вызов методов на хабе SignalR. Сообщения имеют тип `1` (Invocation).

1.  **Создание и подключение к игре:**
    *   **Метод:** `CreateAndJoinGameNew`
    *   **Аргументы:** `gameSettings`, `packageKey`, `[]`, `isMale` (boolean).
    *   **Детали `gameSettings`:** Этот объект должен содержать как минимум:
        *   `Name`: Название игры (например, `testcolabgame_123`).
        *   `Password`: Пароль (`1212`).
        *   Другие необходимые поля для создания стандартной игры.
    *   **Примечание:** Предоставленный в задаче код использует `CreateAutomaticGameNew`, что не подходит для создания игры с паролем. Необходимо использовать `CreateAndJoinGameNew`.

2.  **Отслеживание событий (Server-to-Client):**
    *   Сервер присылает события (тип `1`, `target` с префиксом `On` или другой). Необходимо отслеживать событие подключения нового игрока (`Joined` или `CONNECTED` в протоколе SIGame), чтобы вести подсчет участников.

### Этап 4: Внутриигровое взаимодействие (Протокол SIGame)

Команды внутри игры отправляются через метод хаба `SendMessage`, который принимает один строковый аргумент. Этот аргумент форматируется согласно внутреннему протоколу SIGame (команды и параметры разделены `\n`).

1.  **Запуск игры:**
    *   **Условие:** В лобби 2 игрока.
    *   **Действие:** Отправить команду `START`.
    *   **Реализация:** Вызвать метод `SendMessage` с аргументом `"START"`.

## 4. Детали реализации и ограничения

*   **Язык:** Python 3.
*   **Библиотеки:** Рекомендуется использовать `aiohttp` для HTTP-запросов и `websockets` для WebSocket-соединения, как в предоставленном примере. Скрипт должен проверять их наличие и устанавливать при необходимости.
*   **Асинхронность:** Вся логика взаимодействия с сетью должна быть асинхронной.
*   **Структура кода:** Код должен быть организован в виде класса (например, `SIGameBot`) для инкапсуляции состояния (WebSocket-соединение, ID игры и т.д.).
*   **Ошибки:** Предоставленный в задаче код содержит концептуальные ошибки (неверный метод создания игры, отсутствие обработки `gameSettings`) и должен быть фундаментально переработан, а не исправлен.

## 5. Критерии приемки

Задача считается выполненной, если:
1.  Итоговый продукт — это один `.py` файл, который успешно запускается в ячейке Google Colab.
2.  Скрипт без ошибок создает игру с названием, соответствующим шаблону, и паролем `1212`.
3.  После подключения двух игроков к созданной комнате игра автоматически стартует.
4.  В консоль выводятся логи основных этапов работы бота.
